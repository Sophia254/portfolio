## Project description
Personal portfolio website built for TD-TP 1 of the WAMD module.
I am an Applied Artificial Intelligence student at ENSTA, passionate about data
and web development. The portfolio lets a visitor quickly discover who I am, my skills,
my projects, my education and experience, and my contact information. The site adapts to desktop,
tablet and smartphone screens.

Live website (GitHub Pages, optional): [https://sophia254.github.io/portfolio/](https://sophia254.github.io/portfolio/)

## Technologies used
- **HTML5**: semantic structure (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **CSS3**: CSS variables, Flexbox, Grid, media queries (mobile-first approach)
- **JavaScript**: DOM manipulation and event handling
- **Visual Studio Code**: code editor
- **Google Chrome DevTools**: testing, debugging and responsive simulation

## Implemented features
- Five sections: Home, About, Skills, Projects, Contact
- Sticky navigation with smooth scrolling to each section
- Burger menu on smartphone (button click handled in JavaScript)
- Responsive layout: 1 column (smartphone), 2 columns (tablet), 3 columns (desktop)
- Skill bars animated when they scroll into view
- Contact section with direct WhatsApp, LinkedIn, GitHub and email links
- Original video-editing-inspired design: skills shown as timeline clips, projects as numbered scenes
- Light / dark theme toggle (choice saved in the browser)
- Pastel blue and pink palette with a touch of purple, and basic accessibility (visible focus, contrast, `prefers-reduced-motion`)
